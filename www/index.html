Статика и прокси.
В одном бинарнике.

Router Server раздаёт ваш фронтенд и направляет API-запросы на нужные сервисы по простым правилам из одного YAML-файла.

Возможности

Раздача статики

Отдаёт каталог с сайтом, поддерживает SPA: неизвестные пути ведут на index.html.

Маршрутизация

Правила по регулярному выражению решают, на какой бэкенд уйдёт запрос.

Обратный прокси

Проксирует запросы и добавляет заголовки с IP клиента и версией сервера.

HTTPS

Включается одной настройкой и парой файлов сертификата.

Heartbeat

Эндпоинт для проверки живости сервиса балансировщиком.

Логи

Настраиваемый формат; пароли в запросах авторизации маскируются.

Как работает

  1. Файл? Если путь найден в каталоге статики — он отдаётся сразу.
  2. Маршрут? Иначе сервер ищет подходящее правило и проксирует запрос.
  3. Страница. Запросы браузера за HTML получают index.html приложения.

Конфигурация

root: ./dist
port: 8080
router:
  pattern: ^\/api
  index: index.html
  location:
    "/api":
      url: 'http://backend:8081'
      remove: false
heartbeat:
  path: /heartbeat
  statusCode: 200
